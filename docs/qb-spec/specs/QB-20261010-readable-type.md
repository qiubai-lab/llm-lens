# 可读字号与统一字体 token

授权：用户要求放大偏小文字并统一字号 token。现有颜色变量已建立，字号仍为各文件硬编码，本次实际实施。

## Behavior Delta

### MODIFIED
- REQ-001: 演示说明和操作提示使用 13–15px，候选词 16px，辅助信息至少 12px；移动端保持可读，允许自然滚动。
- REQ-002: 字号统一由 tokens.css 中的尺度与语义变量定义，课程、首页和共享解释气泡复用，断点从统一变量调整。
- REQ-003: 放大后维持已有动态占位、对齐、稳定导航、窄屏无横向溢出及大字号回退。

## Acceptance

- AC-001 [REQ-001]: 实际浏览器检查六幕说明、候选、参数、按钮、提示与解释气泡的计算字号，辅助信息不低于 12px；查看桌面与手机截图。
- AC-002 [REQ-002]: 三个样式文件的 font-size 都由字号 token 或 inherit 提供；UI 规范记录对应语义与维护入口，无新增依赖。
