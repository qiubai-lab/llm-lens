# LLM Lens 学习站 MVP

## 目标与授权
面向普通用户及开发者，交付可由 GitHub Pages 托管的纯静态中文科普站。用户在技术方案讨论后明确要求“为我实现该最小 MVP”，授权实现已讨论的范围。无真实 API 调用、账户、云端存储或线上发布；提供部署工作流。

## Behavior Delta
### ADDED
- REQ-001: 提供首页、学习路径、五章课程、实验室、术语表与来源说明。
- REQ-002: 三个模拟实验支持播放、暂停、单步前后移动、重置、调速与可解释的分支。
- REQ-003: 各章小测验提供即时解释，本地保存完成进度并可继续学习；存储不可用时降级。
- REQ-004: 统一视觉令牌、基础组件、课程结构；支持手机、键盘与减少动画。
- REQ-005: 执行核心与 UI 分离，定义模拟/回放/实时来源契约；MVP 仅模拟，不存储凭证或发起模型请求。
- REQ-006: 产物为纯静态页面，支持 GitHub Pages 仓库子路径、直达与刷新；提供可复现检查和部署配置。

## 验收
- AC-001 [REQ-001]: 首页可进入五章，章节包含目标、直观解释、技术细节、测验及来源；实验室复用三个实验；术语可查找。
- AC-002 [REQ-002]: 单步前后移动可恢复一致状态；暂停/重置无残留推进；切换分支重新开始；工具失败和 Agent 达到上限具有结束解释。
- AC-003 [REQ-003]: 答题显示解释，标记完成后刷新保留，继续学习指向未完成章节；损坏/不可用存储不会导致页面崩溃。
- AC-004 [REQ-004]: 390px 和桌面视口无页面横向溢出；控制具名称、焦点与键盘操作；减少动画下信息和操作完整；展示页复用真实组件。
- AC-005 [REQ-005]: 核心不导入 UI/DOM；回放只投影已存在事件；来源能力明确，真实执行保留独立停止契约，页面明确标注模拟。
- AC-006 [REQ-006]: 类型检查、核心测试、构建和静态链接检查通过；以 /llm-lens/ 前缀预览时资源、章节和导航正常；工作流调用相同验证入口。

## Foundation Decision
- Astro 静态页面与本地 MDX collections；React 作为单个实验的交互容器；TypeScript strict。
- Tailwind/CSS 语义令牌统一风格；shadcn 风格源码组件基于 Radix primitives；Motion 负责 React 动画。
- 页面负责组合，content 管课程，features/experiments 管呈现，core 管无副作用事件与回放，features/progress 管存储。
- 纯静态运行，不引入 SSR、真实供应商连接或服务器。Astro 使用自己的 Vite 集成，不另起应用框架。
- 核心行为以 Vitest 测试；可见体验用 BetterWright 浏览器验证。预览端口只服务本地验收。
- 单个源码文件超过约 300 行进行职责复查，不机械拆文件；样式按 shell、课程与实验归属拆分。

## 页面设计约定
暖白背景、深色正文、蓝色主色，模型紫色、工具青色；正文舒展，实验区域用节点、状态标签与时间线解释过程。首页包含主视觉实验预览与学习路径，课程页桌面侧导航、手机可展开目录。字体使用系统字体，无外部字体请求。页面过渡不阻塞操作，减少动画用静态状态替代。

## 实施中的修正
- 锁定 TypeScript 6.0.3，符合安装版本 Astro check 的兼容要求；采用 `astro/zod` 避免弃用接口。
- 修复延迟加载表单首次点击可能丢失的问题：测验 client:load，实验与测验控件在 hydration 就绪前禁用。
- 修复系统减少动效导致初次 hydration 文本不一致的问题：首先匹配静态 HTML，再应用浏览器偏好。修复后在减少动效下重新验证生成和三实验同页运行，pageerror 为零。
- 工具返回与模型回答时，流程连线显示返回方向，过程面板可见工具参数和示意结果。
