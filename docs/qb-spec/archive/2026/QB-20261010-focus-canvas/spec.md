# 专注演示页

用户批准上一轮方案并要求开始修改。沿用当前 Vite/React 技术栈、教学数据、采样算法及首页，独立演示外壳与舞台。不修改 Agent 入口或部署远端。

## Behavior Delta

### MODIFIED
- REQ-001: 演示页替换网站宣传导航与浮动目录为轻工具栏，提供返回首页、主题位置、目录和显示设置；可选浏览器全屏，退出后保留状态。
- REQ-002: 舞台成为主内容，讲解进程导航稳定在底部，生成操作留在对象附近。桌面常见窗口可见核心内容及导航，不强制缩小字号。
- REQ-003: 参数直接控制同视野概率图；手机采用可切换参数的紧凑控制区并显示当前值，保持自然滚动作为小屏和大字号回退。
- REQ-004: 参数对比成为舞台内部替代布局，关闭对比保留上下文、参数、选中状态；打开目录或显示设置暂停播放，关闭不自动恢复。
- REQ-005: 首页入口、六幕 hash 分享/刷新/返回、气泡解释、采样与生成结果保持兼容，响应减少动态效果，浮层键盘焦点可用。

## Acceptance

- AC-001 [REQ-001]: 首页仍显示项目导航；进入演示后只显示专注工具栏，无悬浮目录压住生成按钮。目录打开/关闭及全屏返回保留演示状态。
- AC-002 [REQ-002]: 1366×768 与 1440×900 六幕导航、上下文与候选均可见；长句和 200% 字体自然滚动，底栏不覆盖末尾内容；生成操作独立于翻幕操作。
- AC-003 [REQ-003]: 390×844 温度场景滑杆与主要概率结果可同时观察；参数切换保留数值，Top-k/Top-p 改变候选；320px 无横向溢出，控件可达。
- AC-004 [REQ-004]: 追加词后进入对比，再关闭后上下文和选词不变；默认与当前参数采用同随机数；播放中打开目录停住，关闭后仍暂停，定时器不继续生成。
- AC-005 [REQ-005]: npm run verify 通过，浏览器验证前进/返回/直接 hash 刷新、概念解释、目录焦点、系统减少动态效果和首页基本交互。

## Evidence

- AC-001：首页保留网站导航；演示使用独立 FocusToolbar，目录不再悬浮覆盖舞台。实测进入/退出浏览器全屏保持上下文，目录与显示设置关闭后保持暂停。
- AC-002：BetterWright 实测 1366×768 六幕无横向溢出，舞台底部 656px、反馈底部 684px、导航顶部 700px；1440×900 六幕可见。200% 字体下自然滚动，末尾反馈位于导航上方。对比最终截图中结果底部 636px、导航顶部 700px，重抽按钮已移至标题旁。
- AC-003：390×844 温度场景概率图和滑杆同屏；移动端切换参数后 Top-k 数值保持。温度两端最大概率约 27.7%/90.6%，Top-k=3 保留三个候选，Top-p=0.1 保留一个。320px 实测无横向溢出，可抽取并追加。
- AC-004：追加后打开/关闭对比，上下文和选词均保持；对比使用同一个 randomAt 值。Top-k=1 与默认参数对比展示不同结果与概率。播放时打开目录或显示设置会暂停，关闭后不会自动恢复；完整生成到结束标记后播放按钮禁用。
- AC-005：npm run verify 通过类型检查、9 项测试、静态构建和子路径资源检查；后续布局调整再次通过 check/build/check:links，组件拆分后 test 再次通过。BetterWright 验证 hash 直接刷新、上一幕/浏览器返回、首页入口、概念解释、浮层 Escape 焦点恢复、系统减少动态效果；页面异常记录为空。
- 核心采样规则与教学数据未改；没有新增依赖。README 与 Directory Map 已同步。
