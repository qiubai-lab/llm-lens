## Design / Foundation Decision

采用已批准的 Vite + React + TypeScript + Motion + CSS/SVG；Radix Dialog/Popover/Tooltip/Slider 承担可访问交互。暖白底、深色文字、蓝色上下文、紫色候选、绿色结果；按场景组织可变舞台，稳定的顶部导航和底部演示控制。首页为编辑式大标题和交互预览，非课程卡片集合。

网站外壳 src/app；通用 UI src/components；主题 src/features/token；纯计算 src/core；设计变量 src/styles。核心不依赖 React/DOM/网络。场景由状态驱动，动画不决定结果。hash 支持静态部署与后退导航；本版不实现真实 API、DSL、账户或存储系统。

现有基础规则与新方案冲突处，用户已批准的重建方案优先；不修改 AGENTS 指令。旧源码先备份到 /tmp/llm-lens-before-deck（旧实现尚未提交）。技术基线 context 仅更新本次明确批准范围。
