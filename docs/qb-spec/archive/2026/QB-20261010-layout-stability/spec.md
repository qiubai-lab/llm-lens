# 动态演示布局稳定性

授权：用户要求修复播放、拆分和导航抖动，并作为项目级设计规范。沿用现有技术栈和教学行为。

## Behavior Delta

### MODIFIED
- REQ-001: 拆分/合并、抽样和连续生成的可预期内容变化不改变邻近操作与舞台下方区域的位置；为候选数量、上下文及提示预留空间；首页小演示也遵守同一规则。
- REQ-002: 六幕底部导航使用稳定区域，首页/上一幕、下一幕/回到首页文案不改变进度与重播位置。
### ADDED
- REQ-003: 项目级规范记录动态内容预留、固定锚点、视觉强调不改几何及实际浏览器验证要求；可访问性与自然滚动保持。

## Acceptance

- AC-001 [REQ-001]: 桌面与手机第一幕反复拆分/合并，按钮及讲解位置不变；天空/蛋糕循环从初始到结束，图表底部、抽样区、操作和参数区锚点保持，选择边框不增高行。
- AC-002 [REQ-002]: 1366px、390px、320px 六幕导航进度、重播与前后操作矩形一致，无横向溢出。
- AC-003 [REQ-003]: 长期 UI 规范落盘并从工程规范关联；200% 字体完整可读、底栏不覆盖滚动末尾，减少动态效果仍可操作；npm run verify 通过。
