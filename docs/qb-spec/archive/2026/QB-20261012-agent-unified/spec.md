# Agent 单一演示与任务卡关联查看

用户本轮明确授权：收窄目录树且内容不换行，模型任务卡可选中并恢复聊天/工作区关联，合并为一个演示，详情改为 dialog 渲染。事实源：[技术设计](../../../../demos/agent-conversation/TECHNICAL_DESIGN.md)。不改变模型/工具协议和模拟边界。

- REQ-001：Agent 只有一个完整 Skill→文件→结果→流式回答演示；首页和目录为单入口，旧六章 URL 可兼容进入统一演示，Token 仍有六章。
- REQ-002：树宽按最长可见内容预算收窄，文件/目录名称不换行，展开和读取状态不推动编辑器左右跳动。
- REQ-003：服务卡支持鼠标/键盘选中；恢复该卡与聊天的连线，工具相关卡同时恢复本地文件及结果连接，打开对应预览；选择不执行工具或修改运行历史，可返回实时跟随。
- REQ-004：卡片详情在可访问的 dialog 里按请求/调用/回答渲染，并可切换原始数据；Escape、焦点返回、内部滚动和窄屏可用；打开暂停运行，关闭不自动恢复。

- AC-001 → REQ-001：路由单测保护 #/agent 与旧六个 URL，首页/目录只有一个 Agent 入口，无章节进度和前后章节导航；完整流程与异常仍可操作。
- AC-002 → REQ-002：浏览器测量树宽较旧比例更窄，文件名/最长目录名保持单行；展开目录/读取后编辑器边界变化 ≤1px，320px/200% 字体无页面横向溢出。
- AC-003 → REQ-003：核心测试保护卡片关联映射、待读取与已执行区别、选择纯读取；浏览器结束后选中历史 Skill/文件/结果/回答卡有对应静态连线，预览正确，执行计数不变，重新发送/执行回到实时模式。
- AC-004 → REQ-004：请求详情显示指令、历史、工具；调用显示名称/参数/结果；回答显示正文/增量；原始 JSON 仍可看。键盘/Escape/返回焦点、打开暂停、320px/200% 字体及 Token 回归验证通过。
