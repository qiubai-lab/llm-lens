# Agent 区域焦点移动与连线绘入

用户明确授权优化步骤动效：接收区域先高亮，边缘焦点在三个区域之间滑动，之后由源区块动态绘出连接。沿用协议与教学模拟，仅改变呈现；事实源为既有主题技术设计。

- REQ-001：使用单一绝对定位焦点框在本地/聊天/服务间移动，当前接收区域有边缘/轻微底色提示；持续增量保留当前区域，不移动实际窗口。
- REQ-002：焦点滑动约320ms后，连线按源→目标绘出约380ms，源点先出现、箭头/目标/标签后出现；同一正文流不因每个delta重画。
- REQ-003：操作可随时打断/重定向，reset/stop/浮层暂停不执行额外工具；历史查看使用静态关联，减少动态效果立即显示静态焦点和完整线；字体/resize/窄屏正确测量，布局稳定。

- AC-001 → REQ-001：浏览器请求→服务器、调用→聊天、执行→本地、结果→聊天、续请求→服务器和正文→聊天，焦点位置与接收方一致，过程坐标存在滑动中间帧。
- AC-002 → REQ-002：实际动画帧证明连线在焦点阶段之后从未绘制到完整；正文多个增量复用同一SVG；历史选中仍有三条静态线与相关区域边界。
- AC-003 → REQ-003：verify、完整交互/暂停/重置/减少动态效果/320px大字体；窗口与发送按钮前后几何不变，无页面溢出。
