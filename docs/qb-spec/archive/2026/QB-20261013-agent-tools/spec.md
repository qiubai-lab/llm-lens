# Agent 工具调度区

授权：用户先批准工具候选区/执行区方案，再明确 next step 后隐藏工具连接、历史选择恢复，最后要求“很好，请你落地修改”。事实源：[技术设计第 9 节](../../../../demos/agent-conversation/TECHNICAL_DESIGN.md)。沿用项目纯核心、语义 token、静态子路径与 BetterWright 约束，不接入真实文件/模型。

## Behavior Delta

### ADDED

- REQ-001：三个候选工具读取/写入/列目录，与请求 tools 定义及计数一致；新增整理并保存预设，默认摘要任务保留。
- REQ-002：工具在完整调用后提升到固定执行区，候选原位占位；返回后展示结果至当前 step 结束，进入下一 step 后恢复候选位；调用记录独立于工具条目。
- REQ-003：执行工具连接目标文件/目录并标明 action；模拟写入只在成功结果时改变模拟工作区，参数/路径/执行时机受校验。

### MODIFIED

- REQ-004：工具相关连接从累计保留改为仅当前语义 step 显示，进入下一 step 隐藏；历史调用/结果选择静态恢复连接、状态与当时快照，绝不再次执行。
- REQ-005：终端输出区域改为工具区，保留文件预览、详情、异常、暂停/停止/重发、键盘与窄屏能力；其他窗口累计连接保持现状。

## 验收

- AC-001 → REQ-001：默认任务 2 次调用/3 轮；保存任务 4 次调用/5 轮，三种工具都被调用，首次请求无文件正文，三工具数量稳定。
- AC-002 → REQ-002、REQ-005：浏览器检查执行位/候选占位、状态、返回与空闲，外框/发送位置稳定，候选点击不自行调用。
- AC-003 → REQ-003：核心测试保护参数/路径、未执行写入、重复结果去重、目录结果、写入成功及缺失失败；浏览器观察三种目标/action 和新文件出现。
- AC-004 → REQ-004：测试与浏览器检查下一行为卡移除本地连接、增量不提前清除；完成后选中历史 step 恢复静态连接/快照，执行次数及最终文件不变，退出清空。
- AC-005 → REQ-005：npm run verify；BetterWright 验证缺失/中断、停止/重发、详情/Escape、桌面/320px/200% 字体/减少动态效果/键盘，截图实际查看。
