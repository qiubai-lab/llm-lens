# Agent 工作台交互与视觉重构

用户明确授权本次设计与交互修改：本地仿真文件管理/终端、中央聊天设计、右侧追加行为卡、各步数据流连线与 action 标签、精简文案、移除底部播放器并由发送按钮启动。事实源：[技术设计](../../../../demos/agent-conversation/TECHNICAL_DESIGN.md)。仍为纯预设教学模拟，沿用 React/Motion、共享外壳与语义字号。

## 需求与验收

- REQ-001：三个工作区具有清晰容器与视觉层次，中央为主角，左侧有可展开文件树、预览编辑器和仿真工具终端。
- REQ-002：发送问题启动流程，工具调用完整接收后提供场景操作以执行读取；停止、重新发送、浮层/后台暂停行为明确。
- REQ-003：右侧行为卡按轮次与阶段追加，正文/参数增量更新对应卡，协议细节按需展开。
- REQ-004：请求、调用、执行、结果、续请求、正文分别连接对应内容锚点，方向与 action 标签准确，减少动态效果保留静态连线。
- REQ-005：删除底部播放、单步、回看、步骤进度和重复概念说明；保留章节导航，异常选择移入场景内。
- REQ-006：保持内容与 call_id 一致、失败/中断语义、Token 路由与采样兼容；窄屏、大字号、键盘可用，非教学锚点稳定。

- AC-001 → REQ-001、REQ-005：截图核对文件树/编辑器/终端、主聊天、行为卡三种层次；无底部播放器或默认 JSON 概念堆叠。
- AC-002 → REQ-002、REQ-006：通过发送→调用就绪→用户执行→回传→回答完成；等待期间无自动读取，停止/重发/浮层暂停不重复或污染状态。
- AC-003 → REQ-003、REQ-006：完整 Skill 任务两次读取、三轮请求；行为卡有序追加且内容与中央/本地同源；异常分支正确。
- AC-004 → REQ-004：浏览器验证六类语义传递的 SVG 连线端点、箭头和标签；缩放/滚动重测，窄屏展开三栏后保持连通；减少动态效果有静态线。
- AC-005 → REQ-005、REQ-006：320px、390px、200% 字体、短视口无页面溢出；发送/导航锚点初始至完成差 ≤1px，足够空间上下留白差 ≤1px；键盘文件与执行操作可完成。
- AC-006 → REQ-006：npm run verify 与 Token 六幕回归通过；文件预览不触发 Agent 上传，终端不执行真实命令。

## Behavior Delta

### MODIFIED

- REQ-001、REQ-003：平铺信息面板改为仿真工作区与阶段行为卡。
- REQ-002、REQ-004：从播放器驱动改为发送与场景操作驱动，数据传递以连接实际锚点的线条表达。

### REMOVED

- REQ-005：移除底部播放/单步/回看条和重复解释文案。

## 验证证据（2026-10-12）

- AC-001：实际查看桌面初始、调用就绪、读取中与完成截图；本地文件树/带行号编辑器/深色工具终端、中央主聊天、右侧淡紫行为卡有独立窗口层次。移除播放器与步骤条，默认无 JSON 大面板/图例/重复段落。
- AC-002：发送后停在 Skill 加载门槛，终端显示“等待执行”；点击后才产生结果，随后项目文件也需要执行操作。停止显示已停止，重新发送清空旧调用，目录打开使按钮转为继续任务，关闭不自动恢复，Escape 焦点回到目录。键盘 Enter 执行后焦点保留在 SUMMARY。
- AC-003：完整正常链路六张服务卡，顺序为用户请求/工具调用/工具结果/工具调用/工具结果/生成回答；两次工具读取、三轮请求。390px 文件缺失返回 FILE_NOT_FOUND，最终任务受阻；流中断保留第一条摘要，服务卡标“中断”，没有正常完成标记。结果文本仍由 core 同源数据输出。
- AC-004：浏览器 MutationObserver 捕获十次语义传递，覆盖请求、调用、执行、结果、续请求和文本六类；SVG data-from/data-to 对应 composer、server-request、server-call、agent-call、file、terminal、agent-result、answer 锚点。读取 Skill 时自动切换文件后重测端点，落在实际编辑器边界。滚动裁切时使用可见区域/端口；窄屏沿外侧轨道垂直连接，标签放在窗口间隙。减少动态效果下 SVG 路径保留、animationName=none；等待交互与完成后停止流动。
- AC-005：1556×1100 桌面六章实际窗口组合上留白124.59375px、下留白124.609375px，差0.016px。发送到完成窗口/发送按钮/导航锚点差0。320px 六章无水平溢出，320px + 200% 字体无溢出，导航三个区域不重叠。长 Skill 编辑器高度263px、终端208px，互不覆盖；编辑器内部滚动。工具卡执行可用键盘，文件夹及文件按钮有展开/选中语义。
- AC-006：npm run verify 通过：TypeScript、5个测试文件共19项测试、Vite静态构建、/llm-lens/资产检查。新增3项 workbench 核心契约测试（先建立缺模块失败证据）；既有6项 Agent 数据测试继续保护 call_id、参数、错误和历史重建。Token 六章实际加载成功，生成选词操作可用。
- 代码边界检查：工作台纯映射归 core；文件/服务/聊天表面、定时器与 SVG 测量归 features。删除旧 Panels/DataFlight/useAgentPlayback，无真实网络、文件读取或命令执行。Directory Map 与 README 已更新；长期 UI/context 未更新。
