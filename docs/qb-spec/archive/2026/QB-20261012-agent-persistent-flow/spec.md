# Agent 慢速、有序、持续连接

用户明确授权：减慢连线切换，已出现的旧线保持存在，在action标签添加序号。复用同源事件历史与现有可见锚点；模拟/调用协议不变。

- REQ-001：按首次语义传递顺序累计连接，连续delta不产生多余线/序号；旧线一直保留至重新开始或重新发送，停止/暂停/选卡不清空旧线。
- REQ-002：焦点约550ms、连线匀速绘入1150ms，主要自动步骤至少间隔2100ms；绘入期间操作仍可打断，减少动态效果即时静态显示。
- REQ-003：标签使用01/02…+action；左右数据流标签各自纵向分布，路径经过标签；旧线降低强调，当前/选中关联突出；窄屏累计标签不重叠、不推动窗口。

- AC-001 → REQ-001：核心测试保护正常10条连接/序号、增量去重、前缀稳定、失败/中断语义；完整流程暂停/选择仍保留历史，reset清空。
- AC-002 → REQ-002：浏览器检查匀速绘入中间帧和2100ms时序，完整3轮/2读取无重复执行，减少动态效果静态可用。
- AC-003 → REQ-003：桌面10条标签不重叠，320px/200%标签可读、无横溢出，窗口/发送按钮几何稳定；verify通过。
