# Architecture

本基线来自用户在 Token 演示重建方案中的明确批准（QB-20261009-token-deck）。单仓库、单静态部署单元，Vite + React + TypeScript + Motion。Node 仅用于开发和构建；无服务器、账户或真实模型连接。

## Ownership

- `app/` 组合首页、全站浮层与主题入口；hash 路由支持静态子路径和分享。
- `features/token/` 拥有六幕演示、生成瞬时状态、参数控件和概率可视化。
- `core/` 提供教学数据及纯采样计算，不能导入 React、DOM、网络或具体存储。
- `components/` 提供词卡、解释气泡与动态偏好；不依赖主题模块。
- `styles/` 集中设计变量、外壳和舞台样式；主题复用语义色与交互习惯。

## State and simulation

状态决定画面，动画不是计算结果的事实源。教学分支与视图解耦；参数影响概率，选词影响下一轮上下文。重抽保持上下文；追加推进上下文；重播恢复可复现的起点。播放定时器清理、切幕重置、后台暂停明确属于 UI。

未来真实模型演示单独设计数据输入能力，不假设普通 API 可以返回完整词表概率、内部向量或隐式思考。当前不预建通用执行框架或适配器。

## Static hosting

`vite.config.ts` 从 `BASE_PATH` 生成静态资产前缀。站内视图使用 hash，工作流按仓库名称配置 base。所有密钥禁止进入静态文件、公开构建变量和 URL。
