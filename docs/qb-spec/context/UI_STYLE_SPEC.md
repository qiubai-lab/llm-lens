# 演示 UI 设计规范

用户明确要求的项目级规范：演示主体在可用舞台区域尽量上下居中，动画表达知识变化，操作位置保持稳定。适用于首页、课程舞台、状态提示和导航；沿用已有设计变量与组件。

- **舞台尽量上下居中**：所有演示的主要内容（上下文、图表、动画和相关操作）作为完整组合，在标题与底部反馈之间的可用舞台区域上下居中；空间充足时组合上、下留白应相等，不将内容贴在顶部而把空白集中在下方。桌面并列参数面板与舞台共同组成居中行，窄屏堆叠后作为整体居中。工具栏、标题、反馈和导航保持各自位置，不参与主体居中。
- **居中服从可读性与稳定性**：共享外壳按工具栏的实际高度分配空间，扣除标题、反馈、导航及安全区；不得用固定像素偏移、整屏绝对定位或变换模拟居中。可用高度不足、内容较长或字体放大时页面自然增高并滚动，顶部、末尾及所有操作均可到达，不裁切、不缩字号。沿用完整状态范围的占位，不能因居中让同一演示中的追加、选中或播放状态带动操作跳动。
- **稳定锚点**：同一演示中的按钮、滑杆、图表边界与导航不因选词、提示文案、候选数量或播放状态改变位置。标题重播与六幕导航的前后操作、进度区域独立占位；短长文案使用相同槽位。
- **先预留，再更新**：有限、可预期的动态内容按完整状态范围预留空间。候选图保留最大行数，上下文按教学分支的换行高度占位；隐藏占位必须 `aria-hidden`，不可交互，不重复播报。未知长度内容可以自然增高，不能裁切、缩小字号或强制锁定页面高度。
- **占位与对齐分开**：预留多行高度后，实际文字仍与同排按钮或图标垂直居中；不能把文字贴在占位容器顶部。不同长度提示及单行/多行状态均需检查视觉对齐。
- **强调不改变几何**：选中、禁用、播放和完成状态保持相同边框、内边距、字号与按钮宽度；边框预留透明尺寸，改变颜色和透明度即可。
- **区分表达运动与布局位移**：词卡移动、概率变化、抽样指针属于教学动画；相邻按钮和说明区被内容推来推去属于缺陷。不要用整块高度或 layout 动画掩盖尺寸抖动；局部词卡运动可以保留，过渡可中断。
- **响应式与可访问性**：占位随实际字体和可用宽度计算；窄屏、大字号与长文本保留自然滚动，固定导航前预留末尾空间。减少动态效果时也必须保持布局稳定。
- **验证动态过程**：前端交付使用 BetterWright 检查桌面与窄屏的初始、选中、追加、结束及反复切换状态。比较关键元素 `getBoundingClientRect()`，普通动画模式下检查过程帧；非教学运动的锚点变化应在 1 CSS px 内。检查 320px 无横向溢出与 200% 字体可读，截图必须查看。CLS 不能代替检查用户交互造成的位移。
- **验证居中与溢出**：逐幕检查桌面与窄屏；内容可完整容纳时，比较舞台区域与完整内容组合的边界，上、下留白差不超过 1 CSS px。同时检查短视口、200% 字体、对比模式与最长生成状态：空间不足时自然滚动，末尾内容能够滚动到固定导航上方，截图需实际查看。不得只以容器居中代替对实际内容的检查。

当前 Token 主题的占位在 `ContextSentence.tsx` 与 `ProbabilityChart.tsx`，导航及控制槽位在 `deck.css`。新增示例或开放实时生成时同步复查占位范围，不能把有限教学分支的策略直接套用于无限输出。

## 字体尺度与语义 token

所有字号由 `src/styles/tokens.css` 统一定义，组件样式使用 `var(--font-size-…)` 或继承。不要在新章节、断点或解释气泡中重新硬编码字号；以阅读为优先，通过间距和自然滚动适应空间。

| 语义变量                   | 默认字号（根字号 16px）            | 用途                         |
| -------------------------- | ---------------------------------- | ---------------------------- |
| `--font-size-meta`         | 12px                               | 编号、辅助标记、概率细节     |
| `--font-size-caption`      | 13px                               | 次要说明、参数值、紧凑对比   |
| `--font-size-control`      | 14px                               | 操作、导航、参数名、生成提示 |
| `--font-size-copy`         | 15px                               | 讲解正文、解释气泡、项目说明 |
| `--font-size-candidate`    | 16px                               | 主概率图候选词               |
| `--font-size-context`      | 桌面 20–24px，手机 18px            | 正在生成的上下文词卡         |
| `--font-size-intro-word`   | 桌面 32px，手机 24px，小屏 20px    | 第一幕拆分/整句              |
| `--font-size-lesson-title` | 桌面 24–32px，手机 24px，小屏 22px | 演示标题                     |

首页大标题、结果词和目录标题使用同一文件中的对应语义变量。正文行高复用 `--line-height-copy`（1.8），常规操作复用 `--line-height-ui`（1.5）。断点只在 token 定义处调整字体尺度，不通过局部缩小说明文字挤入屏幕。

字号变化时同步复核最长候选词列宽、百分比列、按钮标签宽度与提示占位。保持文字完整；空间不足可以换行或滚动。预留文字使用相同字号并参与实际排版，不能依赖原先的小字号像素预算。


## 全站石墨灰与颜色 token（2026-10-12 用户批准）

用户明确要求将已认可的石墨灰主题应用全站并纳入 token 设计。首页、Token 六幕、Agent 与 portal 浮层共享 `src/styles/tokens.css`，不依赖路由切换局部配色。

- 颜色值统一在 tokens.css 定义；组件 CSS 引用语义变量，不复制十六进制/RGB/白色等硬编码配色。新增表面或图表颜色先增加具名 token。
- 表面层级：`--surface-page` 为底色，`--surface-panel` 为两侧工作区，`--surface-primary` 为主演示/聊天，`--surface-raised` 为卡片/浮层，`--surface-inset` 为输入/编辑器，`--surface-terminal` 为终端；模型区可用 `--surface-model`。
- `--ink`、`--text-body`、`--muted`、`--text-subtle` 表示阅读层级；常用正文/辅助文字相对实际表面的对比至少 4.5:1。明亮的语义色只用于文本、数据和边界，实心按钮用 `--action` 与 `--on-action`；图表明亮区段用 `--on-data` 深色文字。
- 蓝色表示输入/当前交互，紫色表示模型/分布，绿色表示选择/结果；错误用 `--danger`。沿用对应 `*-soft` 表面和原有箭头、标签、选中/排除标记，颜色不是唯一说明。
- 概率图以 `--chart-baseline` 表示底层原始概率、`--chart-current` 表示高亮当前概率；抽样/累计区段使用 `--chart-category-1` 至 `6`，保持同一候选索引跨图一致。阈值/抽样指针需清晰区别于区段。
- 边框、遮罩、阴影、滚动条、键盘焦点同样使用共享 token；Portal 在根作用域继承配色。配色调整保持既有字号、几何与动态锚点规则。
